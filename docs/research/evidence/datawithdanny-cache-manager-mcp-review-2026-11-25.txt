## What it does / does not do

- Standalone MCP stdio server + optional Zed editor extension wrapper. Persistent local state defaults to `~/.cache/cache-manager-mcp/`: `sessions.json`, `aliases.json`, and Markdown summaries in `memories/`.
- Session tracking state is not a conversation: timer/session id, label, cwd, timestamps, the last 50 heartbeat/action records, checkpoint counters and optional transcript IDs. `save_memory` stores only a caller-supplied short summary and tags; `resume_or_start` returns the newest matching summary and creates a new tracking session.
- `project_group` is a free-form sticky string on the alias row, defaulting to `cwd` basename. It only buckets dashboard rows/cost totals; it is not a project tree, section/group membership graph, or project-scoped memory store. The README lists project-scoped stores as a future improvement.
- The source explicitly cannot identify native host thread IDs, observe chat activity, clear the active context, open a native thread, or prefill the next chat. Restoring means the model reads a saved memory and the user/client starts a fresh conversation. The server instructions require agent-invoked tool calls, so the automation depends on AI/client protocol support and model compliance.
- Usage/cost collection reads Claude Code JSONL transcripts (default Claude project transcript root or configured override); it does not import those transcripts or calculate equivalent usage for ChatGPT/Codex. Price data is labelled as a June 2026 snapshot.
- No native ChatGPT/Codex connector, Projects/Sections/branch/subtask/event model, attachment-byte reader, skill/MCP/plugin/schedule exporter, target-native session writer, or tests for Claude Desktop gateway Chat/Cowork/Code and local Claude Code API-key mode.

## Disposition

Not a session migration/restore project. Keep only the checkpoint-and-restart-memory pattern as adjacent prior art; do not use its current persistence or dashboard as Nexus's archival backing store without safer file modes, atomic writes, concurrency control, backups, export/import, and tested target adapters.
