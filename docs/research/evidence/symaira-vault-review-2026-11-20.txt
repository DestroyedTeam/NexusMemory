PRODUCT DATA MODEL / IMPORT BOUNDARY
- Symaira Vault is an encrypted local credential vault and MCP/credential service, not a transcript or long-term AI memory store.
- The core data is path-keyed secret entries with fields and metadata, including login/password, notes, URL, TOTP, passkeys, SSH keys, sharing, recipient/identity data, manifest integrity, versioning and vault Git history/sync.
- Readme + `docs/migration.md` document imports from 1Password, Bitwarden, `pass`, CSV/browser CSV, and CXF credentials. CXF collection nesting maps to path prefixes. These are credential export formats, not ChatGPT/Codex chat/session formats.
- There is no ChatGPT/Codex transcript reader or Cloud writer; no Project/Section Group graph, parent/fork/session event model, attachment tree, token/tool-history import, or cross-harness conversation archive.
- “Session Caching” in this project means an unlocked vault session cached in the OS keyring for 15 minutes; it is not an AI conversation session.
- Vault paths such as `projects/local-dev/` are secret namespaces. They do not model ChatGPT Projects or Sections.

HARNESS / MCP / API-KEY VALUE
- `symvault mcp` supports stdio and localhost HTTP; `symvault agent install` writes this service's own MCP configuration for selected clients (documented Claude Code, Codex, Hermes, OpenClaw, OpenCode, and related local agents).
- Agent profiles support `allowedPaths`, MCP tool allowlists/capabilities, scoped expiring tokens, approvals and audit records. Bundled `add-credential` / `rotate-credential` / `find-and-use` / `share-credential` prompts appear as MCP slash commands in supported clients; this is the project's own guided workflow, not an arbitrary Skills importer or cross-harness profile migration.
- YAML API templates and the opt-in egress broker can resolve vault credentials at request time without passing decrypted values into a child process environment/argv/logs. This may be a future optional secret-reference provider for Nexus after explicit authorization; it does not migrate or validate an existing ChatGPT/AWS/Anthropic API key or create a destination Cloud session.
- Platform support in README: macOS Apple Silicon and Linux CLI/server; iOS/Web where applicable; Windows and Intel Mac are unsupported. Not suitable as a universal Windows+macOS harness manager.
- Repository's product-boundary doc says Vault remains an independently usable credential CLI/service, while Brain's normal UI is still an accepted, pending target; no external hosted-service/session migration claim is made.
