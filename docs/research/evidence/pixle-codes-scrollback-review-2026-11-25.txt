WHAT IT ACTUALLY DOES
`scrollback` is a local, offline, stdlib-Python 3.11+ index/search CLI for exactly three *local CLI* history stores: OpenCode, Claude Code CLI, and Codex CLI. It reads OpenCode SQLite via `mode=ro`, Claude/Codex JSONL, flattens selected content into a local SQLite FTS5 database, and offers ranked search, snippets and session listing. Its CLI has `index`, `search`, `sessions`; it has no importer, destination writer, session restore, portable archive, migration mapping, or Harness configuration path.

- The stored session record contains id/source/title/directory/start/stamp and a flat list of text docs. It does not preserve Projects/Sections, parent/child/subtask/branch links (e.g. OpenCode `parent_id`, Claude `parentId`), attachments/images/audio, tool execution state, token/cost usage, or a replayable transcript. OpenCode reasoning and tool input; Claude text and `tool_use` inputs; and Codex text/function/local-shell call inputs are indexed as text, with per-document clipping at 8,000 characters and some parser caps at 2,000. It does not import tool outputs as full structured events.
- “Codex” is Codex CLI rollout JSONL, not the ChatGPT app or Codex app Projects. “Claude” is `~/.claude/projects/**/*.jsonl` from Claude Code CLI, not Claude Desktop third-party-gateway Chat/Cowork/Code. No third-party gateway/API-key data is handled. Skills, MCPs, plugins, schedules, memory and attachments are not transferred.
- Sources are only read; indexing writes a second, consolidated FTS database. There is no encryption or redaction in the index path. The README calls it a private database, but the implementation does not enforce owner-only directory/file modes.

REPRODUCIBLE INDEX PERMISSION / SENSITIVE CONTENT FINDING
`scrollback/store.py:index_path()` makes the configured/default directory with `Path.mkdir(parents=True, exist_ok=True)` and `open_index()` calls `sqlite3.connect`; neither chmods the directory/database nor enables at-rest encryption. The source extractors explicitly index reasoning and arbitrary tool input (including shell command strings, tool input keys/values and written file text), which may contain secrets.
