## Static safety findings (not exploit claims)

- `safe_extract` checks `dest.join(file.name()).starts_with(dest)` lexically. A joined path retaining `..` components can still start with the destination lexically yet resolve outside it. The named test does not test this behavior. This is source analysis only; no exploit was run.
- `agent_dir` interpolates an arbitrary agent string into a filesystem path, and uninstall joins the caller-supplied skill name before `fs::remove_file` without a containment/name check. No destructive command was run against user data.
- The Windows fallback calls `fs::copy` with a directory source, although Rust's `fs::copy` is a file-copy API; platform runtime was not tested.
