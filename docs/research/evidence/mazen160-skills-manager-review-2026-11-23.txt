Executive disposition
High-value adjacent ResourcePlane / supply-chain security reference for scanning and installing Agent Skills across Claude, Cursor, Codex and OpenCode. It is not a Nexus Memory SessionGraph or a ChatGPT/Codex Project/Section migrator. It installs to user-global agent skill directories by default; environment overrides do not add session, project membership, branch/subtask or workspace migration. No Claude Desktop 3P Chat/Cowork/Code session adapter exists.

Observed main-branch implementation
- Python standard-library CLI; no third-party runtime dependencies. It scans GitHub or local Skill sources before copying, with rule/exclusion policy, severity thresholds, JSON and CI output, source metadata, update checks, analysis and uninstall preview.
- Supported targets are global agent skill directories: Claude ~/.claude/skills, Codex ~/.codex/skills, Cursor ~/.cursor/skills-cursor or ~/.cursor/skills, OpenCode ~/.opencode/skills. User environment variables can override these paths. There is no per-session/project/Section store or transfer model.
- Main-branch static scanner inventories files, SHA-256, hidden entries, symlinks/hardlinks, secrets/keys, executable modes, scripts, hooks, registry configuration, binaries, archives and resource limits. It does not execute bundled Skill code. Its default severity ceiling is medium: high/critical findings block; a deliberate --unsafe-install or a higher ceiling can permit risk. Optional AI review is agent-dependent and may pass source/inventory to a configured provider; it was not run.
- Install metadata records the source, optional branch/path, installed name, agent and exclusions, but not a canonical session graph or immutable resolved commit identity. Updates fetch the source and compare installed content.
- Positive design: preflight scan before copy, source-copy snapshot, no-shell subprocess argument arrays, bounded file/scan budgets, explicit exclusion records, preview-before-delete, and same-filesystem temp/backup rename for regular replacement.
