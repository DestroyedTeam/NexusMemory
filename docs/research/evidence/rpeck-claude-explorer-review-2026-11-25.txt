Safety, security, and architectural patterns worth reusing
- Capability-explicit adapter contract: `SourceDescriptor` (`chronological`, `has_projects`, `has_archive_state`, `has_organizations`, `refetchable`, `messages_change_in_place`, `branch_flag`) prevents silently conflating distinct session models across lanes.
- Two-stage write protection (`backend/write_gate.py`, `backend/config.py`):
  1. Corrupt-config safe mode: malformed `config.json` never crashes startup; `Settings.load()` records `config_corrupt_reason` (even when a legacy fallback succeeds), surfaces it in the UI, and halts archive writes until repaired while letting CC image-cache backstop continue.
  2. Cloud-sync write gate: detects Dropbox/iCloud/OneDrive-synced write targets (`data_dir`, `search-index.sqlite`, `cc-images`) and blocks archive writes until explicit consent (`allow_writes_in_cloud_sync` bound to resolved realpath; moving `data_dir` re-closes the gate). MCP notices redact absolute home paths (`_display_home`).
- Codex read-only source isolation (`backend/sources/codex.py`): never mutates `~/.codex`, streams `.jsonl.zst` safely, writes archive copies atomically, and redacts absolute user paths in MCP responses.
- Security & test-integrity discipline (`SECURITY.md`, `TESTING.md §0`): documented HTML-injection fix + regression test for WeasyPrint PDF export, enforced single-credentials-loader invariant (`test_one_credentials_loader`), pre-push secret/path/fixture checklist, and disk-vs-collected test file verification.
