SUMMARY / DISPOSITION
This is a tmux UI plugin that recognizes interactive Claude Code and Codex processes, reads only the first user prompt from their native local session files, and renames the terminal window to a short task title. It does not import, export, restore, move, or rewrite any conversation/session data. It is an adjacent Harness-awareness/metadata UX reference, not a migration product and not a source/target adapter.

DATA / PRIVACY
- Claude lookup reads ~/.claude/sessions/<pid>.json for sessionId/cwd, then the matching ~/.claude/projects/.../<session_id>.jsonl; Codex lookup uses lsof on the running process to find its open rollout JSONL. Codex parser skips auto-injected environment/user-instruction/AGENTS.md preamble entries. Both extract only the first user prompt, truncate it to 400 characters, and do no secret redaction before handing it to the summarizer.
- If OPENROUTER_API_KEY or the tmux @autoname_api_key option is set, the raw prompt excerpt is sent to OpenRouter's chat-completions endpoint for a 3–6 word English title. The key is for title generation only; it is not a session migration or provider-restore key. If no key exists, the plugin uses a 14-character prompt prefix and does not call curl. The source code confirms the API request is plain HTTPS with the excerpt in its user-message body and no redaction stage.
- Only generated titles are cached per session in ~/.cache/tmux-ai-rename; no transcript copy, file hashes, attachments, tool graph or rollback archive is created. The cache is local plaintext and the normal cleanup is --clear. There is no session-data encryption/retention framework.
- A tmux option can hold the OpenRouter API key. No credential was supplied or read during review; avoid embedding actual keys in shared tmux config.

COMPATIBILITY / DESIGN VALUE
- Useful adjacent design ideas: inspect pane process trees; identify a source session through a running process; cache a derived label per source session; use hooks plus a periodic refresh for new-session placeholders; restore the terminal's automatic naming after process exit.
