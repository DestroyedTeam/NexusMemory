## Product boundary

The app scans local Agent Skill directories for four declared providers: Claude Code, Cursor, Codex, and GitHub Copilot. It builds a visibility matrix, validates Skill frontmatter, diagnoses duplicates/broken links, inspects GitHub Skill repositories, stages and reviews files, installs with provenance, supports update diffs/backups, copy/move, and recoverable uninstall. Code uses commit-resolved GitHub tree entries and stores repo/ref/commit/tree SHA metadata. Read access can be extended via user-configured `extraLocations`.

The Claude adapter is a **Claude Code Skills-path** reader (including read-only `~/.claude/skills/synced` discovery); it is not an adapter for Claude Desktop 3P Chat, Cowork, or Code session stores. No ChatGPT/Codex Project, Section Group, transcript/session graph, parent/child conversation, interruption/re-prompt, attachment/media byte, tool-result, token/cost, schedule, MCP-server, plugin, memory, or native resume/restore migration model exists. Shared Skill files do not imply that the surrounding harness history or state is portable. This candidate is useful for Nexus Memory's future ResourcePlane/discovery UX only; it cannot satisfy the SessionGraph transfer objective.

## Source-level safety review

Positive controls are implemented (not just described):

- `validateRelativePath` rejects empty/long/NUL, absolute/drive, backslash, `.`/`..`, Windows-invalid/reserved and trailing-dot/space segments; `safeJoin` rechecks containment.
- GitHub tree symlinks and submodules are skipped; ignored dependency/build directories are filtered. Limits include 500 files/skill, 5 MiB/file, 25 MiB/skill, 200 candidates and bounded concurrency.
- Download requests are pinned to the resolved commit. Staging uses a random directory, `wx` non-overwrite writes and mode `0644`; content is inspected. High-risk findings require a second confirmation, with an explicit warning that heuristic scanning is not a guarantee.
- Existing target content requires consent and is moved to a recoverable backup; install failure attempts to restore the previous folder. Uninstall moves real folders to backup/trash and only unlinks a symlink, not its target. Update previews upstream changes and local edits, then uses the same backup path.
- Optional editor GitHub auth is added only to allowlisted `api.github.com` / `raw.githubusercontent.com` requests; token never enters the webview. The webview CSP uses a nonce and disables inline script. Workspace Trust blocks writes to untrusted workspace locations.

Residuals/bounds: product claims are largely Skill-directory and UI behavior, not migration guarantees. The repo's own dated `docs/ANALISIS.md` lists manual install/update/copy/move/uninstall modal walkthroughs and Cursor Settings discovery as pending; plugin skills, Claude Code enterprise paths and VS Code extension-provided Skills are out of scope; Cursor recursive Skill discovery is not fully implemented; huge GitHub trees can be truncated. The author analysis (2026-10-18) is a small dated market sample with several hypotheses, not evidence of a complete market survey.
