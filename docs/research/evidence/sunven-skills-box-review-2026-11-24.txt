## Product and relevant pieces

Skills Box is a macOS-first Tauri 2 / React 19 desktop app for inventorying, discovering, installing, updating, detaching and uninstalling globally and project-scoped Agent Skills. It delegates package writes to the skills CLI and bundles a vendored Vercel skills agent catalog at source commit a80e4c9d12d607631249d4d7d059f835d4b2f13a, version 1.7.4, with 79 agent definitions. The inspected entries include Codex at ~/.agents/skills and Claude Code at ~/.claude/skills. Project scope means a locally registered filesystem project, represented by a local Project UUID and scoped skill directories, not a ChatGPT/Codex hosted Project or Section Group.

Adjacent ResourcePlane features include source discovery/checks, global versus local-project scope, a native plugin manager for the Claude and Codex CLIs, operation previews, strict skill-id/path checks, backups, diagnostics and an app-data cleanup surface. The native plugin host enum contains only Codex and Claude; operations delegate to their native CLI/plugin marketplace contracts. OperationRecord persists the latest plugin operation per host; it is not a conversation transcript or session archive. No MCP server config import/export is present.

## Source / safety review

CodeGraph indexed 342 files, 8,222 nodes, 41,871 edges; after removing only .codegraph/.gitignore's !.gitignore exception, status is up to date and Git remains clean. Source paths examined include src-tauri/src/agents/catalog.json, scope.rs, scope_layout.rs, security.rs, tasks/install.rs, tasks/uninstall.rs, backup.rs, native_plugins/model.rs, native_plugins/mod.rs, native_plugins/hosts/{claude,codex}.rs and the frontend API.

The code validates Skill IDs as single directory names and rejects separators, dot/traversal, NUL, hidden names and overlong values. Install planning validates the source/target and the scope before invoking the CLI; project writes are constrained to the registered project root. Install/uninstall actions take snapshots and verify postconditions. However, the README explicitly says snapshot restoration is not included. Native plugin removal warns that the host may delete plugin data, options and keys and offers no automatic rollback. GitHub tokens are stored as plaintext in app settings with Unix mode 0600 and are not returned by the read API or forwarded to CLI subprocesses; account-managed native host credentials remain host-owned.
