WHAT IT IS / source-verified behavior
- Claudia is a local Bun/SQLite project-management tool: Projects, Sprints, Tasks, task dependencies, acceptance criteria, statuses, and an MCP server. Database default is `~/.claudia/tasks.db`, override `CLAUDIA_DB`; task context/metadata/tags/images are JSON text columns. Task schema contains `project_id`, `sprint_id`, `parent_id`, `agent_id`, `context`, `metadata`, `images`, and acceptance criteria. `parent_id` constructs task trees; dependency edges are separate. Projects have name/path/description; sprints group work by date/status. None of these entities is a ChatGPT Project, Section, Section Group, or conversation session.
- README advertises “remember context between sessions” with 64KB JSON storage per task. Source confirms `setTaskContext`/`mergeTaskContext` persists JSON on the task and rejects serialized context longer than 65,536 characters. This is task memory, not a turn-by-turn transcript or a memory/session lineage format.
- The only `session_agent_id` is generated as ``session-${randomUUID().slice(0, 8)}`` on MCP server startup and is used to identify the agent claiming/owning tasks. It is not a Claude provider session ID, is not stored as a durable session row, and has no parent/child session graph. Selected current project is an in-memory module variable for the MCP session/process. No transcript importer/exporter or session resume/restore writer was found in source.
- Task images can hold an external URL, local path, base64 value, caption, and timestamp; this is attachment metadata on a task, not images embedded in ordered user/assistant message events. No audio/video/transcript/token-usage/cost event schema was found.
- The repository contains a single `.claude-plugin/plugin.json` plus `skill/SKILL.md` and documents a Claude Code MCP config using `.mcp.json`. This is a Claude asset/integration surface, not a cross-harness asset manager and not a Chat/Cowork/Code session transfer. The repo does not read/import another harness's MCP config or prove that its task context is activated as a native skill.
