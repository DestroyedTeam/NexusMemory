## What it implements

server.py uses FastMCP and mysql.connector pooling to expose employee profile as an MCP Resource, employee CRUD as MCP Tools, and promote_employee as an MCP Prompt. agent.py uses LangChain with Google Gemini 2.5 Flash and langchain-mcp-adapters to connect over SSE, initialize an MCP ClientSession, dynamically load tools, discover resources/prompts, and invoke them. This is a concrete MCP protocol example for one HR/MySQL application, not a universal resource or state migration format. Its ClientSession is the live MCP transport/session handshake, not a durable chat transcript/session-history model; the loop does not persist cross-turn conversation or parent/branch/task graph.

No ChatGPT/Codex Projects/Sections, SessionGraph/turn/branch/subtask import, attachments, token accounting, schedules, durable memory, Skill/plugin portability, Claude Desktop Chat/Cowork/Code adapter, or Claude Code API-Key gateway workflow. The product has two files and no generic harness inventory/serializer.
