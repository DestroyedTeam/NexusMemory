## Product scope and migration fidelity
- README describes a local tmux-based wake/coordination helper: CLI wrapper, markdown duty roster, ring file, and periodic watchdog. Its own limitation says the roster/rings/leases are machine-local and multi-machine fleets need another system. It does not transport the message body; the ring is a wake cue, while durable work must live in an external issue/task board.
- `claudet` wraps terminal CLIs in tmux; `doorbell` types a cue; `lease` writes local scheduling metadata; `watchdog.mjs` checks roster/rings/lease deadlines and may type a wake. This is not a ChatGPT reader or import/export adapter and does not model Project, Section Group, Session, message events, forks/subtasks, attachments, token usage, Skills, MCP, plugins, memory or session schedules. Claude Desktop Chat/Cowork/Code and local Claude Code API-key/gateway sessions are not tested or written.
- README claims cross-harness operation and real-fleet use; those claims were not independently verified. The code is a same-machine terminal wake path, not a durable cross-harness DM channel and not history migration.
