SCOPE / IMPLEMENTATION
- Secretctl is an offline local credential vault, CLI + Wails desktop app + MCP server, not a Harness session manager or converter. It stores encrypted credential records (AES-256-GCM, Argon2id claimed), metadata/tags/expiry and audit log. MCP `secret_list` returns metadata without values; `secret_get_masked` masks sensitive fields; `secret_run`/`secret_run_with_bindings` can inject selected secrets into an allowed child command's environment and sanitize stdout/stderr. MCP `secret_run` requires explicit policy, default deny, and command allowlist. README says no network access for the vault itself; an allowed launched command can still perform its own external actions.
