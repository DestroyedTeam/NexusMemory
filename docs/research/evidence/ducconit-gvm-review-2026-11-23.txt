- Source explanation: `ReleaseAsset` decodes a JSON field named `sha256`; `downloadAsset()` checks the hash only when that field is non-empty. The workflow also publishes `checksums.txt`, but updater code does not fetch/validate that file. **Inference:** with the default GitHub Releases API object, a native `digest` will not populate this custom `SHA256` field unless the release response separately includes `sha256`; actual public API payload could not be fetched from this host (see tool correction). The local fake-server probe proves the critical empty-checksum branch is accepted.
