## Disposition

**Strong ResourcePlane / host integration and native-session-pointer reference; reject as a cross-Harness Projects/Sections/transcript importer.** It manages MCP stacks, local tools/runtimes, multi-harness Skills projections and native CLI launches. README/`AGENTS.md` say provider-native systems remain authoritative for transcripts. No ChatGPT/Codex source parser or Claude Desktop 3P Chat/Cowork/Code session adapter was found.

## Positive patterns

- Canonical `~/.rudi/skills` source projected to host-specific paths (Codex, Claude, Gemini, Antigravity), with digests/ownership receipts, dry-run, drift/unmanaged detection, scoped force, backups/rollback and restart-required reporting. Reuse the reconciliation/ownership model, not blind copy logic.
- MCP/runtime setup and secrets (`~/.rudi/secrets.json`, restrictive permissions) are resource-plane capabilities.
- Agent Host launches native provider CLIs in isolated workspaces and records bounded launch/workspace/artifact metadata. `src/agent-host/resume.js` requires a prior RUDI launch record, existing workspace and non-null native session ID before it asks the provider CLI to resume. This is not a general history importer.
- Agent groups are parallel launch groups (2–10 launches), not parent-child conversation branches.

## False friends and data gaps

`packages/db/src/service/sessions-v2.ts` has a historical RUDI-owned `RudiSession` schema with provider/session ID, project/run-group, origin, title/snippet/status/model/system prompt, timestamps, turn/cost aggregates, cwd/branch/tags and native-storage reference. `packages/db/src/service/migrations.ts` converts only RUDI's own old `projects.json`/`turns.jsonl`; old turn conversion sets assistant response and thinking fields to null. Current CLI explicitly retires `sessions`, `projects`, `import`, and `db`; it does not import provider history and says it leaves `~/.rudi/rudi.db` untouched. Do not count historical database schema as current ChatGPT import capability. No Projects/Section/session-tree, arbitrary transcript, media, attachment, token, memory, schedule or Claude Desktop mode migration.
