## What is actually portable

Mnemark is a local-first knowledge-store CLI. SQLite is durable state; Tantivy and materialized relationship graphs are rebuildable. Its record model stores curated facts/preferences/project knowledge/workflow memories with name, content, tags, global or project scope, source trust, confidence, confirmation, lifecycle/version and provenance. The schema includes memories, ambiguities, changelog, workflow runs, graph assertions/revisions and rebuildable graph tables; it has no conversation/message/session/turn/fork/subagent/attachment tables.

“Project” means a memory type or a scope of the form project:owner/repo; it is not a ChatGPT Project entity and cannot encode Section Groups or nested Session ownership. Graph edges relate curated memory/artifact/workflow records; they are not a transcript event graph. Workflow runbooks and run records are not scheduled tasks. The CLI and bundled Skill do not call an LLM/provider, configure API keys/gateways, or expose a documented MCP server.

The generic JSON import wire format is a memory object requiring name and optional type/content/tags/scope/description/expiry. mem export returns a JSON array of these memory records. Bundle v2 exports Mnemark’s own SQLite memory store plus optional config, manifest and user-created artifacts; bundle import validates hashes/schema and merges or replaces an Mnemark store. These are useful memory backup/transfer capabilities, not ChatGPT conversation import or cross-Harness session migration.

## Agent wiring and target fit

The reviewed setup registry supports five coding CLIs: Claude Code, Codex, Pi, Gemini CLI and OpenCode. Claude Code wiring installs a policy file and bundled Mnemark Skill, and adds a SessionStart hook that checks the exact CLI/Skill version and runs read-only memory priming. It reads prior curated memory; it does not capture the current conversation or import/transcribe past sessions. The other four adapters use instruction/policy prose and Skills where supported. No Claude Desktop 3P Chat/Cowork/Code mode writer, Desktop Code metadata integration, ChatGPT source adapter, Cloud session API, MCP migration or API-key gateway configuration was found.

Security/operational positives: explicit store discovery and preflight; explicit backup-first migration; read-only gate; transaction/rollback setup; memory source-trust and manual-attestation rules; default-reject secret scanning; bounded bundle paths, integrity hashes, and opt-in destructive replace. Security limitation: SQLite stores and bundles are plaintext; there is no at-rest encryption. Bundle SHA-256 is integrity checking, not publisher authentication, so the repository requires private storage/trusted transfer or disk encryption. Secret scanning is defense-in-depth, not complete DLP.

## Disposition

High-value, legally reusable MIT **curated memory-plane prior art / optional memory adapter candidate**, not a ChatGPT-to-Claude conversation migrator. It could receive only explicitly curated memory records or a Mnemark-format store, after provenance, scope and trust are mapped; it cannot reconstruct Destruction Era Project/Section/Session hierarchy, branches, messages, tool events, attachments, token usage, permissions, Skills/MCP/plugins, schedules or desktop gateway settings. Do not count it as migration success. Keep the canonical immutable source archive and SessionGraph separate; any optional projection into a Mnemark-like store must be user-approved, per-record loss-audited, trust-downgraded where appropriate, and protected as plaintext sensitive data.
