## What it is / destination fit

This is explicitly a **Windows-only, Scoop-compatible package manager**, with a shared Go core/CLI/shim and JSON-first CLI plus stdio MCP server. The official MCP guide lists Claude Desktop alongside Claude Code, Cline, Cursor and VS Code Copilot Chat as clients; configuration runs a local binary via `command` + `args: ["mcp"]`, not a hosted Claude API-key gateway. It provides no ChatGPT/Codex Project, Section Group, conversational Session/parent-child/fork, transcript, image/attachment/link/token, Skills bundle, MCP/plugin export, memory, schedule, Claude Desktop third-party-gateway Chat/Cowork/Code history, or local/self-hosted Claude Code history importer. Its runtime manages Windows apps and Scoop buckets, not Harness state.

## Useful adjacent implementation ideas

The source advertises 14 `glue_*` MCP tools, shared with the CLI engine, typed JSON inputs/results, stable exit codes, and per-client registration examples. Write operations normally produce a persisted random confirmation token with a five-minute TTL; `glue_confirm` consumes it once, re-evaluates policy at execution, and logs source/client actor. Deny/protected rules are evaluated before auto-confirm; `agent.auto_yes` or policy mode `auto` skips confirmation. This is a useful local MCP registry/configuration and policy/audit reference, not a session migration protocol. Auto-confirm is a deliberate configuration bypass that a Nexus-style tool should expose as an explicit risk choice.
