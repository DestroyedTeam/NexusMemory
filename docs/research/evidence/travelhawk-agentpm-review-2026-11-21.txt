## What is actually modeled

AgentPM is a Git-native resource manager for agent Skills/agent definitions and provider plugin packages. `agentpm.yaml` declares resource sources, skills, targets, scope, source refs/revisions, and install intent. The internal `RuntimeContextGraph` is `{cwd, configPath, sources, layers, warnings}` where layers are global/project/temporary and entries describe resource provenance and target paths. The `InstallRecord`/registry/cache records track resource identity, adapter, install scope, source, content revision/signature, and link target. This is valuable resource-plane provenance/reconciliation, not a native conversational Project model.

The current adapter union is `generic | codex | claude`; target paths include `.agents/skills`, `.codex/skills`, and `.claude/skills`. Plugin marketplace integration is for Claude Code and Codex. The docs explicitly exclude MCP config installation from the current plan. The project contract/manifests are not ChatGPT Project import, Claude Project import, or session hierarchy.
