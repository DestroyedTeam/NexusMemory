## Implementation findings

- `plugin/hooks.json` registers Antigravity `SessionStart` hydration and `PreToolUse` gating for `write_file|edit_file|run_command`.
- `hydrate-pedagogy.js` reads `~/.ag-memory-mcp/global.db` read-only with `node:sqlite`, selecting at most five `category='pedagogy'` rows from `global_knowledge` or `global_memories`, and formats `systemMessage`/`injectSteps`. It can fall back to `.agents/pedagogy-profile.md`; it does not ingest a transcript, create/update memory rows, or migrate session state. `spec/agent-memory-v3.2-spec.md` is explicitly an RFC proposal for new tables/tools/lazy migration, not implemented code.
- `friction-guard.js` has five regex risk categories, caches by `conversationId:category` for 24 hours, and writes the marker before emitting `ask`. Tests intentionally assert that a second different action in the same conversation/category returns `allow`. The hook receives no approval/denial result, so a prior denial cannot be distinguished from approval; the next matching call is still allowed. Malformed input and unexpected errors also fail open to `allow`.
- Antigravity's current official Hooks docs distinguish `ask` (respects “Always Allow”) from `force_ask` (ignores cached permissions). This source emits `ask`, not `force_ask`.
- Isolated dynamic repro (same synthetic `conversationId`, same temp marker directory; no destructive command was executed): first native payload stdout was `{"decision":"ask","reason":"CRITICAL RISK: Modifying high-blast-radius surface [DESTRUCTIVE_COMMANDS]. Before proceeding, have you engaged the Blast-Radius Critic or Sparring Teammate?"}`; second stdout was `{"decision":"allow"}`. Both Node processes exited 0 with empty stderr. This confirms the bypass state transition at the hook boundary; it does not claim to have exercised the Antigravity UI approval flow.
- `scripts/sync-plugin.js` recursively force-copies the plugin over `~/.gemini/config/plugins/cognitive-personas` without backup/diff/rollback. It was inspected but not run against any user config.
