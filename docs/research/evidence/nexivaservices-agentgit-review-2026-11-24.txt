## What AgentGit actually tracks
- It is a local-first Git companion, not an importer of any existing agent's private history. The operator/agent starts and stops a task; the ledger records manually supplied prompt, agent/model labels, optional summary, validation flags, tags, git SHA/status, changed-file metadata, patch, before/after repository snapshots and parent/flow/branch IDs.
- The Flow graph is task-level lineage: explicit continuation parents and branch labels, with an optional 24-hour prompt-similarity autolink. It does not ingest Claude/Codex/DSH transcript events, create user/assistant turns, preserve interruption/continuation messages, token usage, attachments, Skills/MCP definitions, scheduled tasks, or ChatGPT Projects/Section Groups.
- Repository-local .agentgit stores active-session.json, ledger.json, snapshots, patches and a signature salt. This is useful for future work-change provenance and recoverable file state, but not a portable conversation archive. MCP is a set of start/stop/search/show/diff/context/revert tools for that same ledger, not a Harness-session transport. VS Code contributes timeline/flow UI; it does not add an importer.
- initRepo() creates .agentgit but does not add it to the target repository's .gitignore. README tells users to keep the directory local. A separate .agentgitignore is the only custom snapshot-ignore file implemented; the snapshot walker does not parse ordinary .gitignore. Default filters exclude common build directories and a few log/temp patterns but do not blanket-exclude .env.

## Validation and high-confidence safety findings
- The checked-in smoke script creates and removes temporary Git repositories. After installing runtime dependencies in the isolated disposable clone, npm run smoke exited 0 on Node.js 26.7.0 / npm 11.19.0. CLI task start/stop, file snapshots, search, diff, revert preview/apply, conflict refusal, compare, ledger verification and MCP tools/list/start/stop/search/preview/apply all passed in those synthetic repos. This does not cover hostile ledger paths, sensitive files or cross-Harness migration.
- Synthetic path-traversal reproduction: in a temporary repository, I wrote an unsigned synthetic ledger entry for a created file with relPath ../outside.txt, matching the SHA of a synthetic sibling file. agentgit revert evil-synthetic-session --preview reported “Clean revert: yes” and issued a token. agentgit revert ... --apply --preview-token <token> exited 0 without --force and deleted the sibling file outside the repo. applyRevert() constructs path.join(repoRoot, file.relPath) without containment validation; getSnapshotFile() similarly joins an untrusted relative path. verifyLedger() is not enforced by findSession/revert. The MCP agentgit_revert_apply handler forwards to the same core function, so exposure through that tool is a source-based inference; the CLI path was directly tested. Treat this as a security blocker for reuse or installation against untrusted/shared .agentgit ledgers.
- Synthetic secret snapshot reproduction: in a temporary repo with a valid ordinary .gitignore containing .env, an unchanged synthetic OPENAI_API_KEY .env was copied verbatim into both task snapshots. The task changed only app.txt; ledger changes listed only app.txt and sensitiveFindings was empty. Source shows the sensitive scan runs after capture and only over changed files, then records labels rather than redacting snapshot content. No secret value was real.
- Synthetic flow test succeeded: a follow-up task persisted parentSessionId, shared flowId and branchName; flow show displayed both root and child. This confirms a useful task-lineage pattern, not chat/session import.

## Disposition for Nexus Memory
High-value adjacent task-ledger / flow graph / file-rollback reference, but not a cross-Harness session migrator and not safe to adopt directly. Potential concepts: explicitly typed task lineage, snapshot manifests, before/after file provenance, search/context packs and preview-first reverts. Do not reuse its code or install it in an untrusted repository until path containment, ledger trust, secret-file policy/redaction, default ignore behavior, package-lock URLs and VSIX/source version consistency are fixed. It does not read or write ChatGPT Destruction Era Projects/Section Groups or Claude Desktop Chat/Cowork/Code / Claude Code gateway Sessions.
