Memory fields include ID/hash, scope, kind, title/content, source agent, priority, token estimate, tags, timestamps. MCP exposes memory save/recall, capsule generation, context sync and forget. `ctxbridge sync` targets `AGENTS.md`, `CLAUDE.md`, `.cursorrules`, `CODEX.md`, `.gemini/GEMINI.md`; these are local coding-agent instruction files. There is no ChatGPT/Codex Projects or Section Groups import, conversation/session event model, parent/child task/branch graph, files/attachment payload model, tool-result stream, token-accounting importer, Claude Desktop 3P Chat/Cowork/Code session target or target-native resume/lineage adapter. `ctxbridge capsule` creates a derived bounded memory handoff, not a session transcript. `export_jsonl` selects only memory IDs/records; capsules and their membership are not included.
