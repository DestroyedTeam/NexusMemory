# Candidate #250 — DevExpGbb/swampup-skills (2026-11-24)

## Disposition

A small APM-distributed **Skills catalog**, not a Harness/session migration tool. It is directly relevant only to the user's portable-Skills plane and to understanding the Agent Package Manager distribution path. It contains three static developer Skills, no session parser, memory model, Project/Section representation, message graph, attachment transfer, task schedule, API-key/gateway configuration, or native conversation/resume writer. The target remains ChatGPT **Destruction Era** Projects/Section Groups/full Sessions to Claude Desktop 3P **Chat, Cowork, and Code separately**, plus local/self-hosted Claude Code via API key/gateway; none of that is implemented or tested here.

## What was inspected

The exact repository has root `README.md`, `apm.yml`, `.gitignore`, one `plugins/` tree, and three Skill packages. Each package contains an APM manifest, a Claude plugin manifest, and a `SKILL.md`:

1. `otel-tracing`: guidance for adding OpenTelemetry spans/propagation/export to an HTTP service.
2. `changelog-writer`: Conventional Commit range to grouped CHANGELOG text.
3. `release-notes`: human-facing release text that depends transitively on `changelog-writer`.

`apm.yml` declares these three packages, `apm: []` and `mcp: []`; the root marketplace output block names Claude and Codex. The README recommends APM for other harness targets, but we did not install/run APM to verify emitted files on each target. The independently maintained APM project has a broader target/primitive matrix; that infrastructure must not be attributed to this 3-Skill repository. In APM's current matrix, `claude` means Claude Code, while Microsoft Copilot Cowork is a distinct experimental target—not Claude Desktop Cowork. The matrix describes artifact deployment (skills/instructions/agents/hooks/MCP where supported), not importing or resuming conversations.
