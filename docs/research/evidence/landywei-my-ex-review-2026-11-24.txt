## What the code actually does
- Source is local Codex JSONL only: ~/.codex/{sessions,archived_sessions}/**/*.jsonl plus session_index.jsonl for names. No ChatGPT/Destruction Era import, Claude Desktop, Claude Code, Cowork, or general Harness adapter was found.
- scripts/extract_sessions.py emits a coarse per-session row: ID, source file path, CWD, thread source, created-at/model-provider metadata, counts, first cleaned user ask, last assistant reply, tool names, and a small touched-file sample. It does not preserve the full transcript in the summary row.
- scripts/extract_turns.py emits per-user-turn records containing session ID, turn index, thread name, CWD, a user message and combined assistant text, plus tool-call name/input/output. Tool input/output are capped at 4,000/3,000 characters; user and assistant text at 6,000 each. It filters one known internal-noise prefix. It does not retain message timestamps/IDs, exact interleaving order across assistant text and tool calls, branch/fork/subtask edges, token accounting, or typed media bytes/references.
- extract_text() reads text/input strings from blocks; image/file asset references are omitted. A disposable synthetic fixture with one image pointer returned the text and did not preserve the image pointer.
- Session summaries are compressed by local Ollama qwen2.5:7b-instruct; embeddings/search use local Ollama bge-m3. scripts/mcp_server.py exposes one retrieval tool, search_codex_memory(query, top_k, detailed), usable by MCP clients; it returns selected session/turn excerpts and a path to the original file. There is no native target writer, session restore/import, Project/Section mapper, Skill/MCP package transfer, schedule transfer, memory writer, or rollback path.

## Privacy and portability implications
- The pipeline model/embedding calls target localhost:11434; no remote inference call is implemented in the reviewed code. This is not a guarantee that returned context stays local: an MCP host can pass the selected transcript/tool output to its configured model/provider, and results expose source file paths. No encryption-at-rest or source-level secret redaction was identified. Treat session and tool outputs as sensitive.
- data/ is gitignored and README cautions against committing extracted history. The detailed index is capped/projection-based, not a lossless archive; the original Codex JSONL remains the only transcript-like source and stays one local file pointer away.
