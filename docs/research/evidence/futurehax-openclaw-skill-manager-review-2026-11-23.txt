## Scope and disposition

This is an OpenClaw Skill lifecycle helper, not a cross-Harness migration engine. It has no ChatGPT/Codex Project, Section Group, Session/event/parent-child/fork graph, transcript/attachment, token/usage, MCP/plugin, memory, schedule, Claude Desktop third-party-gateway Chat/Cowork/Code, or local/self-hosted Claude Code reader/writer. SKILL.md itself relies on an agent to detect capability gaps, generate content, and request approval, so it does not meet the user's eventual AI-independent multi-Harness goal. The product's explicit user-approval-before-install workflow is a useful governance pattern only; retain no executable code until licensing and security are resolved. Disposition: `OPENCLAW_SKILL_LIFECYCLE_REFERENCE_ONLY; NO_HARNESS_MIGRATION; README_MIT_CLAIM_WITHOUT_LICENSE_FILE; INSTALLER_PATH_ESCAPE_AND_FALSE_SUCCESS; PYTHON_SOURCE_INTERPOLATION`.

The scripts are unvalidated shell/JSON glue with important unsafe edges. `install.sh` treats skill name and `agent:` scope as filesystem path components without containment checks; chooses repo from pending JSON or an unpinned default GitHub slug; clones current repo content without commit/digest verification; copies directly into destination; and swallows any `pending.sh remove` failure. It checks an existing destination only if it already contains `SKILL.md`, then reports installed regardless of whether the required file landed at the reported path. `pending.sh` embeds names/descriptions/repos directly into Python source and rewrites JSON in place without locking or atomic replacement. `status.sh` makes GitHub API calls via curl and interpolates the name in Python. `create.sh` creates a public org repository (`private:false`) before local commit/push, may leave an orphan repo on later failure, and falls back from `GITHUB_WRITE_TOKEN` to `GITHUB_TOKEN` even though the read token is documented as usually insufficient for writes. The credential-bearing remote URL is briefly stored in temporary git configuration. No live GitHub write was attempted.
