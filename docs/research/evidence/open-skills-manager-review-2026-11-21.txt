## Implementation and safety observations

- Skill repositories are cloned/pulled to an OS temporary cache using Git argument arrays. Skill scanning searches nested directories for SKILL.md frontmatter. Local groups are IDE-specific skill directories.
- Cloud search combines claude-plugins.dev and GitHub repository search. The external skill path requests a ZIP through github-zip-api.val.run, extracts it with adm-zip, selects a directory containing SKILL.md, then copies it into the active IDE skill directory. No actual cloud query or skill install was performed in this review.
- src/utils/fs.ts copyRecursiveSync removes an existing destination directory recursively before copying. This helper is called by repository installs and the remote ZIP path without a backup/undo transaction. The ordinary UI action is user-triggered, but a collision can replace custom local skill contents.
- Static path-boundary finding: sanitizeDirName replaces separators and punctuation but leaves dot components. In a non-destructive Node check, input name "." remained ".", resolving the install destination to the skills root; input ".." remained "..", resolving to its parent. The cloud install path later removes any existing targetDir recursively before copying. Thus an untrusted catalog skill name "." or ".." could escape the intended skill directory and delete an adjacent folder. This path effect was calculated without deleting anything; the remote catalog input and full VS Code command path were not runtime tested.
- Dependency audit of package-lock.json with npm audit --omit=dev against registry.npmjs.org exited 1 and reported one high-severity direct dependency group: adm-zip locked at 0.5.16, package range ^0.5.12. The code uses adm-zip for remote downloaded ZIP extraction. GitHub advisories identify high-severity unbounded ZIP uncompressed-size allocations for affected adm-zip versions; npm audit offered 0.6.1, outside the current ^0.5.12 range. This is a dependency finding and relevant attack surface, not a reproduced crash. A separate advisory describes symlink-following extraction; the extension extracts to a fresh temporary directory, so exploitability of that specific path was not established.
- The cloud search uses public catalog/GitHub endpoints without provider credentials. The manager does not store or migrate agent conversation context.
