## Scope and disposition

`inneros-personal-brain` is a long-term shared-memory / personal-brain backend (Cognee graph memory, Bright Data retrieval, AWS Strands orchestration, optional local Qwen/vLLM, and a bounded Docker artifact path). It is **not** a ChatGPT/Codex Projects, Section Groups, transcript, session-tree, or cross-Harness migration/import/export program. Keep only the high-level shared durable-memory sidecar as an adjacent MemoryPlane research reference; do not reuse it as Nexus Memory's SessionGraph or target writer. This is a **memory-only, not a migrator** disposition.

- `docs/COGNEE_AGENT_MEMORY_FABRIC.md` describes a shared memory surface for multiple agents/harnesses, but it does not define source transcript ingestion, Project/Section mapping, or a full-fidelity session interchange schema.

## Security and synthetic data probes

`app/memory_curator.py` redacts several labeled secret patterns, bearer strings, `sk-...`, long hex strings, private IPv4 ranges, and some home-directory paths. A synthetic offline probe showed it did not redact the test email `person@example.test`, test AWS-like access-key string `AKIAIOSFODNN7EXAMPLE`, or macOS path `/Users/alice/Library/Application Support/app/config.json`; it did redact the synthetic password/API key and `127.0.0.1`.

More importantly, `app/cognee_agent_tools.py` exposes `cognee_remember(data)` that truncates and forwards supplied text to Cognee without calling the curator. `CogneeMemoryStore.add()` likewise serializes text/metadata without curator enforcement. A direct-tool POC used a fake HTTP client and synthetic-only values; the request body preserved both a synthetic secret and private path:

```json
{"tool_result":{"ok":true,"provider":"cognee","dataset":"inneros-personal-brain","stored":true},"request_body_contains_synthetic_secret":true,"request_body_contains_private_path":true,"synthetic_auth_used":true,"request_body":"Verified fact api_key=SYNTHETIC_SECRET_TOKEN and /Users/alice/private/session.jsonl"}
```

The model-facing system prompt is not a security boundary. A migration product must run a deterministic, comprehensive redactor immediately before every shared-memory writer, preserve provenance/consent, and keep raw transcript content local by default.
