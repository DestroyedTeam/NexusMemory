## Disposition

**Keep only as a limited portable prompt/skill-content library and format-emission reference; reject as a cross-Harness session/project importer.** It reads 15 repository-owned `SKILL.md` patterns and emits text/config files for Claude Code, Antigravity, Cursor, Windsurf, Roo/Cline, Copilot and `AGENTS.md`. It has no ChatGPT or Codex adapter, no Claude Desktop 3P Chat/Cowork/Code target, no MCP, no plugin/account/gateway configuration, no project/session/message/transcript/attachment/token graph, and no supported export/import format. `/teach` describes user-authored on-disk learning files for continuity, not reading or migrating ChatGPT/Claude session state. `/schedule-loop` is a workflow prompt, not a native scheduled task.

## Format mapping and semantic loss

- Claude Code exporter writes `.claude/commands/<name>.md` plus `CLAUDE.md`, with `$ARGUMENTS`; it does **not** emit the current recommended `.claude/skills/<name>/SKILL.md` bundle. Anthropic says `.claude/commands` remains a legacy supported path, while `.claude/skills` is the recommended native Skill format. Source: https://support.claude.com/en/articles/14554000-claude-code-power-user-tips ; https://platform.claude.com/docs/en/managed-agents/skills .
- Antigravity gets `.agents/skills/<name>/SKILL.md` plus copied sibling files; Cursor gets `.mdc` rules plus `.cursorrules`; Windsurf and Roo/Cline receive flattened text rules; Copilot and generic `AGENTS.md` receive one flattened document. These are prompt/resource projections, not conversation-history transfers.
- Matrix claims “any harness,” but implementation supports only the explicit `EXPORTERS` map. It omits Codex, ChatGPT, Claude Desktop 3P, MCP, connectors/plugins, session trees and project hierarchy. Target mode and provenance are not represented.

## Safety/reliability review

`cli/sync.py` offers no `--dry-run`, ownership manifest, diff, backup, rollback or safe merge. Exporters directly `write_text()` target files. A synthetic test preseeded an existing target `AGENTS.md` and `.github/copilot-instructions.md` with unrelated sentinels, then ran the documented exporter against a disposable directory; both sentinels disappeared and both files were replaced with generated 70,422-byte output. Other exporters also overwrite rule files; repeated `CLAUDE.md`/`GEMINI.md` behavior is marker-dependent (overwrite when marker exists; append otherwise). The `name` from skill frontmatter is joined into output paths without path containment validation (static observation; no traversal POC performed). This is unsafe as a general-purpose no-review “sync” into an existing project without an external backup/diff/ownership layer.
