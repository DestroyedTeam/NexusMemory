## Disposition

**Pass as a direct cross-Harness/session migrator; retain as a useful adjacent Skills-registry and ingestion-security reference.** The repository is a Next.js + PostgreSQL web registry for SKILL.md assets, not a project/session export-import system. Its Prisma `Session` is auth state (`token`, `userId`, expiry, IP/user-agent); there are no agent project/section/group/conversation/message/branch/transcript/attachment/media/token-usage models. MCP is one imported community catalog type, not a persisted per-session MCP configuration graph. No plugins, memory, schedules, or Claude Desktop Chat/Cowork/Code session semantics are represented.

## What is technically useful

The strongest implementation ideas are the explicit PRIVATE/UNLISTED/PUBLIC access policy, owner/fork/version relationships, content-addressed SHA-256 blobs, and a defensive Skills ingestion pipeline. Code at `lib/skills/github.js` validates HTTPS `github.com` source URLs, constrains manual redirects to `api.github.com`/`codeload.github.com` with a maximum of three hops, sends `GITHUB_TOKEN` only to the API host, applies a 30-second timeout and compressed-download cap, then passes archives through ZIP/path/Markdown checks. `lib/skills/zip.js` enforces streaming compressed/uncompressed/file/entry/ratio limits and rejects Unix symlink/device entries. `lib/skills/paths.js` rejects absolute, drive, control-character, dot/traversal, overlong and overdeep paths. `lib/skills/ingest.js` requires one root `SKILL.md`, validates frontmatter/content, hashes files and builds a version content hash before storing blobs. The app's community feed fetches third-party `aitmpl.com` JSON for skills/agents/commands/settings/hooks/MCPs/mods; that is a catalog feed, not import of Harness-specific session data.

## Important verification gap / CLI naming hazard

README claims `npx skillary add @owner/slug`, but repository `package.json` is `name=skillary`, `private=true`, and has no `bin`; local public UI code copies `npx skillvault add`. `npm view skillary ... --json` resolved version `0.0.3`, repository `yurtsever/skillary`, binary `skillary: dist/index.js`; that separate package's GitHub README describes a read-only local instruction-file browser invoked as `npx skillary`, not this registry's `add` command. `npm view skillvault ... --json` resolved version `0.13.2`, description “SkillVault — secure skill distribution for Claude Code”, binary `skillvault: dist/cli.js`, with no repository URL reported. The advertised installation route is therefore not proven to belong to this repository; do not run it blindly.
