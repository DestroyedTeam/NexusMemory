## Product and scope fit

A cross-Harness `guild-appoint` Skill for Claude Code, Codex, and DeepSeek Harness (DSH). The entrypoint requires explicit appointment, loads a small roster/project-membership summary, then expands profiles and QuestBoard details on demand. The bundle has a Skill, three public profiles, Markdown roster/protocol/templates, a Python package/reference checker, and an optional PowerShell DSH adapter. This is a collaboration convention and Skill distribution—not a conversation importer, canonical memory archive, Project manager, or native Session manager.

QuestBoard consists of manually maintained project-local Markdown (`成员.md`, `消息列表.md`, per-message detail files). It may record a roster, tasks, message IDs and statuses, but its rules are not filesystem access controls and it has no daemon, automatic wake-up, or session-resume writer. Public names/titles do not create product hierarchy. It cannot stand in for ChatGPT/Codex Project/Section Group structure or source session history.
