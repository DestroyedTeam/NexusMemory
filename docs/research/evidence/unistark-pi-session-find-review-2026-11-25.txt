# Candidate #262 review — uniStark/pi-session-find (2026-11-25)

## Decision
**Useful Pi-specific session-content search and branch-awareness prior art; not a migration adapter.** It exposes Pi's current session history in a TUI `/find` overlay, including optional abandoned-branch search, but does not export a provider-neutral record, import sessions, create Projects/Sections, or move any data to Claude Desktop or Claude Code.

## Implementation behavior
- Registers a Pi TUI `/find` extension. In non-TUI mode it only notifies that interactive mode is required. It reads the current session from `ctx.sessionManager.getBranch()`; `--all` instead uses `getEntries()`, then labels each hit active/inactive from entry IDs. This supports reading abandoned branch entries but does not preserve parent IDs, branch topology, or cross-session relationships in its own output.
- Splits entries into `user`, `ai`, `thinking`, `tool`, and `meta` searchable pieces. It keeps per-entry IDs and display timestamps. Text/thinking/tool-call arguments/tool results/`!cmd` and summaries can be searched; image data is reduced to a `[图片]` placeholder and unsupported block types are dropped. It does not retain model/provider/usage/tokens, attachments, links as typed assets, or any export manifest.
- The default view hides thinking/tools; Ctrl+K/Ctrl+T or options can show them. `--all` is about abandoned branches, not all categories. The UI can open a selected entry through `ctx.navigateTree`; that intentionally moves the user's session position on Enter. Browsing/querying itself does not write the session file or add text to model context.
- Code defect/coverage gap: `entryPieces` creates the `meta` category for `custom_message`, `compaction`, `branch_summary`, and image placeholders; `ALL_CATS` displays a System label. But all presets omit `meta`, there is no CLI option or key to toggle it, and hidden-match messaging only offers thinking/tool toggles. Thus this category is currently unreachable in the UI.
- No ChatGPT source parser, Projects/Section Groups, session export/import, Claude Desktop Chat/Cowork/Code target, Claude Code API-key/gateway adapter, or Skills/MCP/plugin/schedule transfer exists. This is a single-Pi reader extension.

## Nexus Memory disposition
Keep as a **small conceptual source-reader/UI reference**. Its content-block categorization and active-vs-abandoned view point toward a canonical model that separates ordered events, typed content blocks and branch membership. Its own `Hit` projection flattens branch links to a boolean and drops media/source metadata; do not use it as a lossless SessionGraph or transfer path. The inaccessible `meta` view and lack of tests should be recorded, not silently generalized as robust coverage.
