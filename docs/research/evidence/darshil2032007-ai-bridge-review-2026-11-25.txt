## Implementation findings

- README and MV3 manifest describe a browser extension for ChatGPT, Claude.ai, Gemini, Perplexity and Grok; no desktop app, Codex native storage connector, local Claude Code CLI, or Claude Desktop Chat/Cowork/Code mode connector exists.
- `src/adapters/ChatGPTAdapter.ts::extractMessages()` scrapes currently rendered DOM into role/content strings; it does not read an export or persist source IDs, timestamps, project membership, branches, files, assets or tool traces. Fallback selectors can produce layout-dependent extraction. `src/types/conversation.ts` permits optional `timestamp`, but this adapter never populates it.
- `src/context/ContextEngine.ts::generateContextPackage()` truncates conversations to the first and most recent 49 messages above 50. `src/utils/groq.ts::formatMessagesForPrompt()` truncates each message to 2,000 characters. The full text of the retained messages is POSTed to `https://api.groq.com/openai/v1/chat/completions` for a generated summary; parsing coerces absent fields to defaults. ContextPackage includes summary/task/decision/code/file-name strings, not a graph or archive.
- `src/context/PromptBuilder.ts::buildContinuationPrompt()` creates a prompt; `src/background/background.ts::executeTransfer()` opens a new platform homepage and injects that prompt. It cannot select an existing Project, create/restore target-native history, or retain source event identity.
- No Skills, MCP, plugin, memory store, schedules, project/section group, subagent/fork graph, attachment-byte, token ledger, or native target import model was found in the reviewed tree.
- README calls the extension “100% Local” and says it has no backend/database, but source calls Groq's hosted endpoint. Correct interpretation: no AI Bridge-owned server; processing is not local-only. API key is kept under Chrome local storage key `ai_bridge_settings`.
- README badge claims MIT, but `rtk find 'LICENSE*'` found no license file; registry SPDX stays null. Reuse license is unconfirmed.
