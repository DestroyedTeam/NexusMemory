SUMMARY / DISPOSITION
This is a Windows-local web dashboard and operations/control plane for CLI terminals (Claude Code, Codex CLI, Cursor agent and shells), not a cross-Harness project/session importer. It searches and resumes histories in their original workspace; it has no target-native writer or ChatGPT Projects/Section Groups, Destruction Era hierarchy, Claude Desktop third-party Chat/Cowork/Code session adapter, or cross-Harness archive/restore path. Keep as an adjacent UX/reference for local session search, outputs and source-native resume; do not reuse as the migration engine.

SCOPE AND MODEL
- README describes live terminal screens, creating terminals in a folder, full-history search, continuing hits via `claude --resume` / `codex resume` in the original folder, outputs, GPU queue, operator sessions and Tailscale phone access. Requirements state Windows 10/11 and Node.js 20+.
- `hub/searchindex.js` incrementally indexes only Claude Code local transcript JSONL beneath `~/.claude/projects` and Codex CLI rollout JSONL under `~/.codex/sessions`. The indexed session record is flat (source session ID, file, offset, mtime, cwd, title, first prompt and message list); it has no source project/section/branch/parent-child graph or target-native serialization.
- Parsing retains selected user/assistant text and short tool-call hints, filters metadata/sidechains/noise and large tool outputs/attachments, and truncates each indexed message to 6,000 characters. It is a search index, not a lossless archive. No ChatGPT, Claude Desktop app Chat, Cowork or Desktop Code-mode store is parsed.
- The index persists compressed JSON documents in `hub/.search-cache.json.gz`. The source uses gzip, not encryption; the root `.gitignore` excludes it from version control, which does not protect local contents from filesystem access. Cache did not exist in the clean cloned checkout.
- Access is sensitive: README warns that anyone holding the hub token can drive terminals on the PC; the app limits listening to loopback/Tailscale and has an origin guard. This privileged terminal access is unrelated to migration and should not be treated as a safe public session bridge.
