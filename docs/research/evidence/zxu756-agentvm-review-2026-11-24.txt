## Source-level boundary

`SnapshotNode` / `SnapshotLineageQueryEngine` model VM disk/config snapshots and snapshot ancestry, including parent/fork snapshot identity, LCA/diff/GC, and a safety snapshot before restore. The snapshot covers the guest root disk/config, not guest RAM. Project directories mounted from the host using VirtioFS are outside that disk snapshot. The README warns read-write VirtioFS shares are inherited by branches and concurrent branches can overwrite common host files. The default guest uses system NAT; outbound firewall enforcement was still planned for M5, so this is not an API-key egress sandbox.

The CLI/stdio MCP operate VM lifecycle, execution, snapshots and restore. No import/export adapter for ChatGPT Projects/Sections, Session events/branches, Skills, MCP server definitions, plugins, memories, attachments or scheduled tasks was found in the reviewed scope. Keep snapshot ancestry separate from conversation-session lineage.
