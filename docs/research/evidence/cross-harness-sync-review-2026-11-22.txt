## Value for Nexus Memory
This is the strongest candidate so far for a narrow NarrativeStatePlane / cross-machine handoff pattern: explicit current/task/blocker records, a six-section handoff, decision index plus retrieval-only archive, git-diffable provenance, and named mechanical checks. It can inspire a derived checkpoint that points back to lossless source records. It must not replace SessionGraph: it stores human/agent-authored summaries and can omit or falsify what happened. It has no media/attachment payload, message/branch/subtask event graph, source identifiers, actual token measurement, memory-store import, or automatic platform adapters. It is therefore useful for continuity between tasks, not exact ChatGPT-to-Claude session migration.

## Local implementation issues reproduced on isolated synthetic data
1. Force-refresh can overwrite partially edited user state despite the README promise to preserve edited state. The current main branch treats any line containing an unfilled placeholder as template-owned. A synthetic CURRENT.md row “| Current stage | production complete <one line> |” still passed is_template_shaped(); copy_file(..., force=True, protected=True) returned “wrote:” and replaced it with the untouched template. The synthetic value was created and destroyed only in a TemporaryDirectory.
2. Secret-ignore verification can report a false PASS when a negating gitignore rule re-includes a secret path. In a temporary repo with .gitignore lines “.env” then “!.env” and a synthetic .env, the current main check_secrets_ignored invokes git check-ignore -v and treats its exit 0 as ignored. Independently, git check-ignore -q -- .env returned 1 (not ignored). The verifier recorded [PASS] for that .env. No secret values were read; the .env content was a dummy fixture.
3. The cross-platform harness fails on macOS at the common install-layout gate. On this host os.name is posix, stat.FILE_ATTRIBUTE_REPARSE_POINT is 1024, but os.stat_result has no st_file_attributes. scripts/ai_common.py::_relocated accesses path.stat(...).st_file_attributes unconditionally when that constant is present. The repository verifier command exits 1 with an uncaught AttributeError before printing checks. A representative full-suite failure hits the same traceback. This is a portability/runtime failure, not a test-only assertion.
4. Current main test suite, run from the required dev venv: 555 collected; progress stream counted 298 passed, 252 failed and 5 skipped; command exit 1. The first integration failure and sync_verify failure share the AttributeError above. GitHub release notes report 550/5 on the release tree, and open PR #7 reports 564/5 on its implementation commit; neither is the same current main tree nor a reproduced macOS pass.
5. Current main has additional known state-safety gaps that PR #7 explicitly targets: its installer considers partially filled placeholder lines untouched; its secret-ignore logic accepts a matching negation rule; the migration validates --authorizations-dir only when supplied as a flag, not the effective path read from config. The PR changes template-slot matching, uses git check-ignore -q, centralizes repo-relative path validation, and records/retries failed migration commits; those repairs are still draft/unreleased. This review did not execute a path-escape migration against any non-temporary tree.

## Recommendation
Retain as a **high-value narrative-state / handoff architecture reference**, not as a migration implementation or cross-Harness compatibility proof. Borrow the explicit L0/L1/L2 state separation, minimal handoff template and provenance pointers only in a separate derived-state plane. Do not install the current main branch into real memory state: force refresh can overwrite partially filled state and the secret-ignore check can falsely pass a re-included .env. Reconsider its code only after draft PR #7 is merged/released, the POSIX verifier crash is fixed, and the relevant behaviors are reproduced on each target harness/OS. Keep user-authored source transcripts, branches/subtasks, attachments, tokens, memories and schedules in an independent lossless SessionGraph.
